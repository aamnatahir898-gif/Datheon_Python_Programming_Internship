## Projects and Tasks

### 1. Hangman Word Guessing Game
A console-based game where players guess a hidden word one letter at a time.

**Key concepts:** Random selection, loops, conditional statements, sets, and input validation.

### 2. Stock Portfolio Performance Tracker
A Python application that calculates stock investments, market values, profit or loss, and portfolio returns.

**Key concepts:** Dictionaries, financial calculations, CSV file handling, and data validation.

### 3. Nova Customer Support Chatbot
A rule-based chatbot that responds to customer queries about business hours, products, delivery, returns, payments, and order tracking.

**Key concepts:** Regular expressions, JSON, string processing, functions, and conversation state management.
